# Historical assignment packets

`task-packets/` preserves the former `tasks/` directory byte-for-byte, including
its original README and version labels. Those labels describe historical inputs.
The current runner does not consume these packets. Current definitions live in
`stages/`; preparation generates and freezes inputs for each run.

Old paths in frozen runs remain historical evidence. The relocation does not
change instructions, implementations, evaluations, or acceptance claims.
