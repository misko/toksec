# Repository map

The parent reads `AGENTS.md`. The measured builder receives `RULES.md`, selected
stage instructions, and a generated artifact contract. Current runners never
import the legacy pilot.

| Location | Owner and purpose |
|---|---|
| `README.md` | Current entry points and limitations |
| `AGENTS.md` | Parent/contributor working rules |
| `RULES.md` | Shared Stage 1–5 builder policy |
| `contracts/` | Schemas for submissions and parent evaluation records |
| `stages/` | Current stage requirements, language policies, and suite selections |
| `tasks/v8/` | Generated Stage 1–5 packets; edit sources and regenerate |
| `tasks/v2/` through `tasks/v7/` | Historical generated packets |
| `toksec/` | Stage 1–5 runtime and shared artifacts, storage, transport, accounting, and publication |
| `stage10/` | Experimental Stage 10 runtime and partial grader |
| `evaluation/` | Executable checker and calibration code, not evaluation results |
| `evaluate.py` | Thin Stage 1–5 standalone and tagged-grading CLI |
| `scripts/` | Campaign orchestration, analysis, plotting, calibration, and publication commands |
| `tests/` | Harness regression tests and test-only implementation fixtures |
| `fixtures/` | Shared accounting test data |
| `results/` | Curated implementations, instructions, accounting, and parent evaluations |
| `references/` | Engineering reference implementations and their separate validation evidence |
| `diagnostics/` | Published calibration evidence about the measurement machinery |
| `docs/` | Current guides and explicitly indexed historical records |
| `legacy/python_pilot/` | Original Python pilot, including its prompts, configuration, and task |

## Runtime ownership

`toksec/storage.py` owns durable atomic JSON writes. `toksec/api.py` owns the shared
Responses transport, including its fixed endpoint and no-retry policy.
`toksec/metering.py` owns shared accounting constants and pure usage calculations.
The Stage 1–5 campaign ledger, Stage 10 request ledger, and legacy pilot ledger
retain their distinct reservation policies. Extraction does not change prices,
authorized budgets, or model settings.

Stage 10 definitions and fixtures live in `stages/stage10/`. The experimental
runtime remains in `stage10/`. Its frozen draft policy and host readiness records
are labeled in that stage's README; they are not evidence of full acceptance.
Stage 1–5 fingerprinting excludes Stage 10's separate definition tree.

The limited Rust server formerly named `starters/static.rs` is now
`tests/fixtures/implementations/static.rs`. Tests use it; builder input assembly
does not. There is no starter-code input to current campaigns.

## Local data and history

`.runs/` holds raw campaign repositories and audit evidence. `.calibration/` holds
raw diagnostic work. Both are ignored by Git but must be archived deliberately,
not treated as disposable caches. `__pycache__/` is disposable generated bytecode.
`.git` is Git-managed; in a linked worktree it is a pointer file.

The relocation does not rewrite `.runs/`, published `results/`, reference validation,
or historical task packets. Old paths in frozen records describe their original
checkout. New preparations receive new fingerprints. Use the recorded historical
checkout for old runs instead of adding path shims or modifying their manifests.

For permanent artifact placement and parent report ownership, see
[result storage](result-storage.md).
