Retained artifact: dcdb837a1c6e4a4c98ee2207212fa5ed. All 16 Level 2 public checks passed, including in three fresh-start revalidations with empty server diagnostics. The server implements nonblocking epoll-driven persistent HTTP, GET/HEAD, ordered pipelining, confined regular-file serving, limits and timeouts. This is Level 2 only; TLS, proxying and Level 3–5 capabilities are not implemented.

Performance: two complete alternating comparisons were ineligible because of generator/environment saturation, so neither challenger was promoted and no speedup is claimed. In the second comparison the retained server's five-round median goodput (range), worst p99, and total failures were: fresh 4 KiB/256: 69,946 requests/s (66,336–79,440), 7.2 ms, 0; fresh 64 KiB/256: 32,490 (31,057–34,410), 12.9 ms, 0; persistent 4 KiB/256: 5,954 (5,872–5,997), 44.5 ms, 0; persistent 64 KiB/256: 123,216 (97,051–130,393), 8.2 ms, 0; fresh 4 KiB/4096: 50,129 (45,184–55,076), 1,093.9 ms, 2,992; fresh 64 KiB/4096: 34,056 (20,574–36,373), 1,242.1 ms, 2,671; persistent 4 KiB/4096: 78,582 (61,910–88,752), 117.6 ms, 0; persistent 64 KiB/4096: 67,305 (28,854–74,292), 256.7 ms, 0. These closed-loop figures are inconclusive and not an open-loop capacity guarantee. Detailed per-round measurements, including throughput bytes, p50/p95, timeout counts, CPU, RSS and generator lag, belong to the controller's benchmark artifacts; their numerical values were not available in the rollover summaries and are not reconstructed here.

Known limitations: the retained parser rejects non-UTF-8 header field values; a byte-oriented parser snapshot passed tests and revalidation but was not promoted. The retained epoll mask can repeatedly wake for a half-closed, write-stalled peer; an unpromoted alternative passed the public and restart suites, and the underlying effect was reproduced in a bounded socket test. An extracted timeout-predicate test showed that an incomplete pipelined header's deadline is not checked while an earlier response is writing; this was not reproduced end-to-end. The implementation bounds buffered request bytes and serves responses sequentially but does not explicitly count buffered pipelined requests against pipeline_depth. High-load fresh-connection failures remain unresolved. Finite tests do not establish complete security or reliability.

Unsafe usage: direct Linux libc FFI for epoll_create1, epoll_ctl, epoll_wait, openat, sendfile and close, including raw file-descriptor ownership conversion and a packed epoll event structure.
