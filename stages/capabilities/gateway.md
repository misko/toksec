# Shared gateway API

Use Stage 2 static-file and connection behavior, including 403 for directories. On gateway requests require one Host. GET and HEAD /gateway/<path> go to the configured origin_address, removing /gateway and preserving the query and Host. Relay the origin status and exact body with Content-Length. Local routes never depend on an upstream. Use HTTP/1.1 with Content-Length upstream; no chunked coding is required. Distinguish local filesystem routing from upstream URI handling. Do not emit hop-by-hop or client-controlled connection headers to the origin. A failed origin returns 502. Gateway benchmarks use /gateway/data/{size}, except admission uses the public route /data/{size} to measure unaffected service and upload uses POST /gateway/upload with the workload bytes echoed by the origin. A 429 is never a successful-service sample. All servers start with an empty workspace.
